# Accessories — Equipment Slot API

[![Download Latest](https://img.shields.io/github/v/release/forwardfrostview/accessories-slot-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/forwardfrostview/accessories-slot-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A flexible accessory slot API for Fabric providing ring, amulet, and charm equipment slots.

![Accessories — Equipment Slot API Preview](https://cdn.modrinth.com/data/jtmvUHXj/images/4712cd37a214152bf2931819ce190d7501551138_350.webp)

## Features

- Flexible equipment slot system for accessory items
- Built-in rendering for visible worn accessories
- Event hooks for equip, unequip, and tick
- Compatible with attribute modifier system
- Fabric alternative to Curios API for Forge

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
